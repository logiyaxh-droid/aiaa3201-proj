## 1. 项目定位与目标

### 1.1 核心任务

**输入**：低分辨率视频（320×180，x4 bicubic 下采样）
**输出**：高分辨率重建（1280×720）
**关键要求**：不只是逐帧提升空间细节，还要**有效利用并维持跨帧的时域一致性**

PDF 原话："The system must not only enhance spatial details of individual frames but also effectively and utilize and maintain temporal consistency across the video sequence."

### 1.2 四个核心概念（报告里必须讲清楚）

| 概念 | 对应方法 | 你要回答的问题 |
|---|---|---|
| **Image Interpolation**（空间重采样） | Bicubic / Lanczos | 为什么插值有天花板？ |
| **Feature Alignment**（特征对齐） | Optical Flow / Deformable Conv | 相机在动，怎么找到"同一个点"？ |
| **Multi-frame Fusion**（多帧融合） | PCD Alignment + TSA | 邻帧信息怎么加权合并？ |
| **Perceptual VSR**（感知式复原） | Spatio-temporal GAN + Temporal Loss | 为什么感知好但 PSNR 低？ |

### 1.3 三个 Part 的逻辑链

```
Part 1 手工基线         →   Part 2 SOTA 复现        →   Part 3 探索
   ↓                          ↓                          ↓
证明"逐帧独立"不够        证明"对齐+融合"和           尝试解决
（无时域一致性）           "时域感知"各自的价值         遗留缺陷
```

**关键认知**：Part 1 的 EDSR 在合成 bicubic 数据上会赢插值，但**因为是逐帧独立处理，没有任何时域一致性**——这正是引出 Part 2 的伏笔。报告里必须把这个"trade-off"讲出来。

#### Step 3：时域基线（多帧平均）

PDF：
> Algorithm: For each frame, perform a weighted average of its spatial neighbors (after Bicubic upscaling) to observe the effect of simple temporal fusion on denoising and sharpening.
> Advanced Idea: Apply Unsharp Masking on the averaged result to enhance high-frequency edges.

实现：
```python
# 对每帧 t，取 [t-k, ..., t+k] 的 bicubic 上采样结果做加权平均
# 权重可以用高斯核（中心权重大）
def temporal_avg(frames, kernel=(1,2,3,2,1)):   # k=2，5 帧
    w = np.array(kernel, dtype=np.float32); w /= w.sum()
    out = sum(wi * frames[t + i - k] for i, wi in enumerate(w))
    return out

# 进阶：对平均结果做 Unsharp Mask
from skimage.filters import unsharp_mask
sharp = unsharp_mask(avg, radius=1.0, amount=1.5)
```

**预期结果**（PDF 明确写了）：
> The EDSR baseline should improve detail reconstruction over interpolation on synthetic bicubic data, while processing each frame independently and therefore providing no explicit temporal consistency.

**我实测的基线数字**（clip 000 第 2 帧，给你一个量级参考）：

| 方法 | PSNR |
|---|---|
| Bicubic 上采样 | **25.85 dB** |
| EDSR x4 | **27.95 dB** |
| EDVR L x4（5 帧输入） | **30.94 dB** |

这个梯度很清楚：插值 < 单帧CNN < 多帧对齐+融合。**你的结果应该在同一量级**，如果差太多就说明有 bug。

## 6. Part 2：SOTA 复现

### 6.1 EDVR（多帧对齐 + 重建）

PDF：
> EDVR is a landmark video restoration method based on Pyramid, Cascading and Deformable (PCD) alignment and Temporal and Spatial Attention (TSA) fusion.

#### 技术要点（报告里要解释清楚）

1. **PCD Alignment（金字塔+级联+可变形）**
   - 金字塔：多尺度下采样，大运动在小尺度上更容易被捕捉
   - 级联：粗尺度对齐结果作为细尺度的初始偏移
   - 可变形：学习 offset + modulation mask，实现亚像素级、非刚性的特征对齐
   - **这就是为什么你需要编译 DCNv2**

2. **TSA Fusion（时域空间注意力）**
   - 对每个邻帧计算一个空间注意力图，决定"哪些位置的信息值得信"
   - 解决遮挡、出画、快速运动区域的融合问题

3. **滑窗 vs 循环**
   - EDVR 是**滑窗式**（每次看固定 5 帧），不是循环传播
   - 优点：可并行、可检查；缺点：长时序信息不传递

#### 实现

```python
import sys, types
import torchvision
mod = types.ModuleType('torchvision.transforms.functional_tensor')
from torchvision.transforms import functional as F
for n in dir(F): setattr(mod, n, getattr(F, n))
sys.modules['torchvision.transforms.functional_tensor'] = mod

import torch
from basicsr.archs.edvr_arch import EDVR
from PIL import Image
import numpy as np

CK = "/data/disk1/shared/aiaa3201/checkpoints/EDVR_REDS_SR_L/EDVR_L_x4_SR_REDS_official-9f5f5039.pth"
ck = torch.load(CK, map_location="cpu", weights_only=False)["params"]
model = EDVR(num_in_ch=3, num_out_ch=3, num_feat=128, num_frame=5,
             deformable_groups=8, num_extract_block=5, num_reconstruct_block=40,
             center_frame_idx=2, hr_in=False, with_predeblur=False, with_tsa=True)
model.load_state_dict(ck, strict=True)
model = model.cuda().eval()

# 5 帧滑窗：取 center_frame_idx=2 为中心
def edvr_infer(clip_dir, center_idx):
    frames = [center_idx-2, center_idx-1, center_idx, center_idx+1, center_idx+2]
    imgs = []
    for i in frames:
        i = max(0, min(99, i))          # 边界复制
        p = f"{clip_dir}/{i:08d}.png"
        a = np.array(Image.open(p).convert("RGB"), dtype=np.float32) / 255.0
        imgs.append(torch.from_numpy(a).permute(2,0,1))
    x = torch.stack(imgs).unsqueeze(0).cuda()   # (1,5,3,180,320)
    with torch.no_grad():
        y = model(x)                             # (1,3,720,1280)
    return y[0].clamp(0,1).permute(1,2,0).cpu().numpy()
```

**实测输出**：`(1,3,720,1280)`，范围 `[-0.015, 1.030]`（要 clamp 到 [0,1]）。

#### 两种权重怎么选

| 权重 | 训练数据 | 用在哪 |
|---|---|---|
| `EDVR_REDS_SR_L` | REDS | **主实验**（REDS 是主战场） |
| `EDVR_Vimeo90K_SR_L` | Vimeo-90K | Vimeo 上的对照 |

**注意**：EDVR 对退化类型敏感。REDS 的 bicubic 退化和你手上的 `val_sharp_bicubic` 是一致的，所以效果会好。如果换成自拍视频，性能会明显下降——**这本身是个好的分析点**。

### 6.2 TecoGAN（时域一致感知增强）

PDF：
> TecoGAN is a classic video super-resolution method that uses a recurrent generator, a spatio-temporal discriminator and a warping-based temporal loss to encourage plausible details that remain coherent across frames.

#### 技术要点

1. **循环生成器（recurrent generator）**
   - 上一帧的 HR 结果 + 光流 warp → 作为当前帧的先验
   - 不是"看 5 帧"，而是"带着历史往前走"

2. **时空判别器（spatio-temporal discriminator）**
   - 不只判断单帧真假，还判断**帧间运动是否合理**
   - 这让生成器不敢逐帧乱猜细节（否则时域上会被识破）

3. **Warping-based temporal loss**
   - `L_temporal = || warp(HR_{t-1}, flow) - HR_t ||`
   - 强制相邻帧在运动补偿后保持一致

4. **为什么 PSNR 会低**
   - GAN 追求"看起来真实"，会**脑补纹理**
   - 脑补的内容和 GT 不一定对得上 → PSNR 降，LPIPS 升（变好）
   - **这正是 CV 里最经典的 accuracy-vs-perception trade-off**

#### 实现

TecoGAN 官方代码是 TF1（[thunil/TecoGAN](https://github.com/thunil/TecoGAN)）。流程：

```bash

# 推理（注意 --checkpoint 指向老师的权重）

  --checkpoint /data/disk1/shared/aiaa3201/checkpoints/TecoGAN/TecoGAN \
  --input_dir LR --output_dir HR
```

**关键**：`--checkpoint` 要指向共享盘路径前缀（不含 `.index`）。

#### 验收标准

- 输出 HR 帧的**时域闪烁明显小于** EDSR/EDVR
- 静态区域的纹理更"锐"，但可能出现**偶发的纹理漂移**（这是 GAN 的典型 artifact）
- 报告里要贴**连续 3–5 帧的对比图**，让人一眼看出闪烁差异

### 7.2 为什么推荐 Direction C

PDF 原文：
> Generative models often create artifacts. Design a system that calculates Pixel-wise Uncertainty. Use BasicVSR++ for certain regions (e.g., text, faces) and Generative models for uncertain textures (e.g., grass, water).

**三个理由**：

1. **不依赖能否下到 checkpoint**。A 和 B 都要 HF 权重，而这台机器 `huggingface.co` 不通。C 用的是 BasicSR 系模型（你已经有 EDVR）+ 你自己算的不确定性，**完全可控**。

2. **技术含量足够高**。你需要：
   - 设计像素级不确定性度量（可以用 test-time augmentation、多模型分歧、或者特征方差）
   - 做区域路由（soft mask / hard threshold / learned gate 三种都试）
   - 融合两个模型的输出（加权、泊松融合、或者频域融合）

3. **报告好写**。可以画：
   - 不确定性热力图（哪些区域"拿不准"）
   - 路由 mask 可视化
   - 融合前后对比
   - 定量：PSNR/SSIM/LPIPS/tLPIPS 四指标 vs 两个单模型

### 7.3 Direction C 的具体实现路线

```
输入 LR 视频
    ↓
┌───────────────┬────────────────┐
│  EDVR 推理     │  EDSR 推理       │  （两个已有的模型）
│  （稳、锐但可能糊）│  （保守、不脑补）  │
└───────────────┴────────────────┘
    ↓                    ↓
   D_edvr              D_edsr
    ↓                    ↓
  ┌──────────────────────────┐
  │  不确定性估计 U(x,y)       │
  │  U = |D_edvr - D_edsr|    │  ← 最简单：两模型分歧
  │  或：test-time aug 方差    │  ← 更严谨
  └──────────────────────────┘
    ↓
  区域路由：U 高 → 信任 EDSR（不脑补）；U 低 → 信任 EDVR（细节好）
    ↓
  融合：F = M·D_edvr + (1-M)·D_edsr,  M = smooth(1 - U)
    ↓
输出 HR 视频
```

**三个可以做的实验**（够写 1–2 页）：

1. **不确定性来源对比**：两模型分歧 vs TTA 方差 vs 特征方差，哪个更可靠
2. **路由策略对比**：hard threshold / soft sigmoid / 学一个轻量 gate
3. **定量结果**：四指标 vs EDVR 单模型、EDSR 单模型

**预期结论**：在"两个模型都不确定"的区域（草地、水面、树叶），混合策略能保住 EDVR 的细节；在"EDVR 可能脑补"的区域（文字、人脸边缘），回退到 EDSR 能提升 PSNR。**总 PSNR 略升，LPIPS 基本持平或略降**——这是个可信的结论。

## 8. 评测指标实现

PDF 6.2 要求四个指标，其中 **两个要自己实现**。

### 8.1 PSNR / SSIM（现成）

```python
from skimage.metrics import peak_signal_noise_ratio as psnr
from skimage.metrics import structural_similarity as ssim
import numpy as np

def calc_psnr(pred, gt):        # pred, gt: HxWx3, float [0,1] 或 uint8
    return psnr(gt, pred, data_range=1.0)

def calc_ssim(pred, gt):
    return ssim(gt, pred, data_range=1.0, channel_axis=2)
```

**注意**：PSNR 要在 **Y 通道**上算（业界惯例）还是 RGB 上算？PDF 没说死，**选定一种并在报告里声明**。建议用 RGB（简单，且 REDS 官方评测也是 RGB）。

### 8.2 LPIPS（现成，实测通过）

```python
import lpips
loss_fn = lpips.LPIPS(net='alex').cuda().eval()

def calc_lpips(pred, gt):       # 输入范围 [0,1] 的 tensor (1,3,H,W)
    with torch.no_grad():
        return float(loss_fn(pred*2-1, gt*2-1))   # LPIPS 要 [-1,1]
```

**实测**：bicubic vs GT = **0.5279**，self vs self = **0.000000**（sanity check 通过）。

> 注意：第一次运行会下 alexnet 权重（233 MB），从 `download.pytorch.org` 走，实测可用。之后缓存在 `~/.cache/torch`。

### 8.3 时域指标：两个不同的东西，别混用

> **P0 更正。** 本节此前把 `LPIPS(warp(I_{t-1}), I_t)` 写成了「TecoGAN 定义的 tLPIPS」，
> 那是错的：那是**自一致性**诊断指标，没有 GT；TecoGAN 的 tLP 是**相对 GT** 的参考式指标。
> 两者排序可以相反，混用会直接得出错误结论。以下为更正后的版本。

#### (a) 参考式 tLP —— 与论文可比，必须有 GT

TecoGAN（[Chu et al., TOG 2020](https://arxiv.org/abs/1811.09393)）`metrics.py` 里的定义：

```
d_SR(t) = LPIPS(SR[t-1], SR[t])
d_GT(t) = LPIPS(GT[t-1], GT[t])
tLP(t)  = |d_SR(t) - d_GT(t)|
```

要点：

- 在**所有**合法相邻帧对上取均值；缺帧处断邻，不跨 clip。
- 没有连续 GT 时返回 **N/A**，不要填 0（Vimeo-90K 只有 `im4` 有 GT，就是这种情况）。
- TecoGAN 官方脚本还会 `cutfr=2`（首尾各排除 2 帧）并对两路输入做 `crop_8x8`
  （裁到 32 的倍数，720×1280 → 704×1248）。是否对齐这些细节要写明，
  只对齐公式就写「按原始定义重实现」。
- 官方报告的是 **tLP×100**；用原值时必须标清单位。

已实现并逐项验证：`p0/evalkit/temporal.py`，验证记录 `p0/audit/tlp_check.json`
（GT 当输出 → 0；无连续 GT → null；逐对交叉校验 6.2e-09；×100 比值 100.000000；
cutfr=2 从 99 对降到 95 对；缺帧断邻）。

#### (b) Flow-warp LPIPS —— 自一致性诊断，无 GT

```
flow_warp_lpips = E_t [ LPIPS( warp(I_{t-1}, F_{t-1→t}), I_t ) ]
```

它衡量「输出序列自己有多稳」，**不需要 GT**，所以能在 Vimeo 与真实视频上算。
但它的数值同时被空间质量影响：一个模糊但平滑的输出会拿到很低的分数。
**不能**用它替代 (a)，也不能用它的低值断言「某方法最稳定」。

#### (c) 本项目旧表里的 `tLPIPS` 列是什么

是 (b)，且 **stride=2**（只测隔一个的相邻对，100 帧 → 50 对）。
原值已复现，误差 1.5e-10，仍保留在 `p1/metrics/*.json` 里，列名改称 `Flow-warp LPIPS`。

同一 clip 000 上的对照说明为什么必须分开：

| 方法 | 旧 `tLPIPS`（=flow-warp, stride2） | 正式 tLP |
|---|---|---|
| Bicubic | 0.0569 | 0.0261 |
| TecoGAN（+0.375 预平移，12 帧样例） | 0.0787（全量）/ 0.0232（前 12 帧，shift=0） | 0.0047 |

#### (d) 光流方向：已用合成样本标定

`p1/scripts/flow_gt.py` 用已知 12 px 平移自证约定：

```python
f = cv2.calcOpticalFlowFarneback(gray_T, gray_S, ...)   # 目标在前、源在后
warped = cv2.remap(S, gx + f[...,0], gy + f[...,1], ...)
```

写成 `fb(S, T)` 会让误差上升约 30%（L1 1.36 → 34.85）。这条与 (a)(b) 都无关，
但任何 warp 相关实现都应先跑一遍。

> PDF 只要求「Temporal Consistency」，没强制用某个具体指标。无论用 (a) 还是 (b)，
> **都要在报告里写清是哪一个**，并且同一个结论只用同一个指标支撑。

### 8.5 评测脚本骨架

```python
import os, glob, json
import numpy as np
from PIL import Image

GT_ROOT  = "/data/disk1/shared/aiaa3201/project1_video_sr/val_sharp"
LR_ROOT  = "/data/disk1/shared/aiaa3201/project1_video_sr/val_sharp_bicubic"
OUT_ROOT = "/tmp/nick_work/outputs"

def evaluate(method_name, infer_fn):
    results = {}
    for clip in sorted(os.listdir(GT_ROOT)):
        gt_dir = f"{GT_ROOT}/{clip}"
        lr_dir = f"{LR_ROOT}/{clip}"
        frames_pred, frames_gt = [], []

        for f in sorted(glob.glob(f"{gt_dir}/*.png")):
            name = os.path.basename(f)
            gt = np.array(Image.open(f).convert("RGB"), dtype=np.float32)/255.
            pred = infer_fn(lr_dir, name)      # 你的推理函数
            frames_pred.append(pred)
            frames_gt.append(gt)

        # 逐帧指标
        ps = [calc_psnr(p, g) for p, g in zip(frames_pred, frames_gt)]
        ss = [calc_ssim(p, g) for p, g in zip(frames_pred, frames_gt)]
        lp = [calc_lpips(to_tensor(p), to_tensor(g)) for p, g in zip(frames_pred, frames_gt)]
        # 时域指标（整段一次算）
        tl = calc_tlpips(frames_pred)

        results[clip] = {
            "psnr": float(np.mean(ps)), "ssim": float(np.mean(ss)),
            "lpips": float(np.mean(lp)), "tlpips": tl,
        }
        print(f"  {clip}: PSNR={np.mean(ps):.3f} SSIM={np.mean(ss):.4f} "
              f"LPIPS={np.mean(lp):.4f} tLPIPS={tl:.4f}")

    # 跨 clip 平均
    agg = {k: float(np.mean([v[k] for v in results.values()]))
           for k in ["psnr","ssim","lpips","tlpips"]}
    print(f"\n[{method_name}] AVG: {agg}")
    json.dump({"per_clip": results, "avg": agg},
              open(f"{OUT_ROOT}/{method_name}_metrics.json","w"), indent=2)
    return agg
```

## 11. 已知坑清单

按踩坑顺序排列，全部实测过：

### 11.1 环境类

| # | 现象 | 根因 | 解法 |
|---|---|---|---|
| 1 | `conda create` 报 `CondaToSNonInteractiveError` | anaconda 官方 channel 的 ToS 未接受 | 加 `--override-channels -c conda-forge` |
| 2 | `pip install basicsr` 报 `No module named 'torch'` | build isolation 里没 torch | `--no-build-isolation` |
| 3 | 装 basicsr 报 `No module named 'cv2'` | setup.py 的 `get_hash()` 会 import 整个 basicsr 包 | **先装 opencv-python-headless** |
| 4 | 报 `ImportError: Unable to get git version` | 源码无 `.git` | 手写 `basicsr/version.py`：`version = '1.4.2'` |
| 5 | 报 `No module named 'yaml'` | 缺依赖 | 装 pyyaml lmdb scikit-image tqdm addict future requests yapf |
| 6 | 装 torch 后 `No module named 'torch.sparse'` | 下载不完整 | `--force-reinstall --no-deps torch==2.6.0` |
| 7 | `No module named 'tb-nightly'` | 该包在镜像上不存在 | **跳过**，不影响推理（只训练用） |

### 11.2 DCN 编译类

| # | 现象 | 根因 | 解法 |
|---|---|---|---|
| 8 | `setup.py build_ext --cuda_ext` 报 `option not recognized` | **不存在这个参数** | 用环境变量 `BASICSR_EXT=True` |
| 9 | `.so` 生成了但 `deform_conv_forward_cuda` 找不到 | 编译时走了 CPU-only 分支 | 检查 `TORCH_CUDA_ARCH_LIST=8.6` 和 `CUDA_HOME` |
| 10 | `ModulatedDeformConv got unexpected keyword 'deform_groups'` | 参数名不同 | 用 **`deformable_groups`** |

**验证 DCN 是否真的编进 CUDA 的可靠方法**（别信 import）：
```bash
nm -D --defined-only basicsr/ops/dcn/deform_conv_ext*.so | grep deform_conv_forward_cuda
```
应该有 `_Z24deform_conv_forward_cuda...` 这样的符号。

### 11.3 模型/数据类

| # | 现象 | 根因 | 解法 |
|---|---|---|---|
| 11 | EDVR `load_state_dict` 报 80 个 unexpected keys | `num_reconstruct_block` 默认值不对 | 改成 **40**（不是 20） |
| 12 | `torch.load` 报 `File is not a zip file` | BasicSR 权重是**老式 tar** | `weights_only=False`，且不要用 `zipfile` 检查 |
| 13 | `torchvision.transforms.functional_tensor` 不存在 | torchvision ≥0.17 删了该模块 | 运行时打 shim（第 4.3 节有代码） |
| 14 | Vimeo 的 `input/` 当 LR 用导致 PSNR 虚高 | `input/` 是已上采样的 | **LR 用 `low_resolution/`，GT 用 `target/`** |
| 15 | Vimeo tLPIPS 算不出来 | 每个 clip 只有 im4 有 GT | **只在 REDS 上算 tLPIPS** |
| 16 | EDSR 输出尺寸不对 | 把 1280×720 当输入了 | EDSR 输入是 **320×180**，输出才是 1280×720 |

### 11.4 网络/系统类

| # | 现象 | 根因 | 解法 |
|---|---|---|---|
| 17 | `git clone` 挂起 | git 协议被封 | 用 `codeload.github.com` tarball |
| 18 | `pip install git+https://...` 卡死 | 同上 | 下 tarball 本地装 |
| 19 | HF 模型下不到 | `huggingface.co` 不通 | 别依赖 HF，用老师给的权重 |
| 20 | **磁盘满**（`/data/disk1` 只剩 8 GB，99%） | 全班共用 + 家目录在上面 | **`rm -rf ~/.cache/pip`** 释放 12 GB；环境放 `/tmp`（挂 `/`，有 85 GB） |

### 11.5 TecoGAN 特有

| # | 现象 | 根因 | 解法 |
|---|---|---|---|
| 21 | TF 1.15 装了但 `No module named 'tensorflow_core'` 之类 | protobuf 版本太新 | 钉 `protobuf==3.20.3 numpy==1.18.5 h5py==2.10.0` |
| 22 | `tf.test.is_gpu_available()` 返回 False | **TF1.15 只带 CUDA10，A6000 是 sm_86** | **接受 CPU 推理**，在报告里说明 |
| 23 | TecoGAN 输出是 4 个 clip 的格式 | 它默认给的是 Vid4/TOS 场景 | 自己准备 `LR/` 目录，按它的命名放帧 |

## 附录 A：一键环境脚本

```bash
#!/bin/bash
set -e
export PATH=/usr/local/cuda-12.4/bin:$PATH
export CUDA_HOME=/usr/local/cuda-12.4
export TORCH_CUDA_ARCH_LIST="8.6"
export BASICSR_EXT=True

WORK=/tmp/nick_p1
mkdir -p $WORK && cd $WORK

echo "=== [0/6] 清理磁盘 ==="
rm -rf ~/.cache/pip || true
df -h /data/disk1 | tail -1

echo "=== [1/6] 建 py3.10 环境 ==="
/opt/miniconda3/bin/conda create -y -p $WORK/srenv --override-channels -c conda-forge python=3.10
PY=$WORK/srenv/bin/python
PIP=$WORK/srenv/bin/pip

echo "=== [2/6] 先装 opencv，再装 torch ==="
$PIP install -q opencv-python-headless
$PIP install -q torch torchvision --index-url https://download.pytorch.org/whl/cu124

echo "=== [3/6] 其他依赖 ==="
$PIP install -q pyyaml lmdb scikit-image tqdm addict future requests yapf lpips imageio-ffmpeg

echo "=== [4/6] BasicSR 源码安装 ==="
curl -sSL -o bsr.tgz https://codeload.github.com/XPixelGroup/BasicSR/tar.gz/refs/heads/master
tar xzf bsr.tgz && mv BasicSR-master bsr_src
printf "version = '1.4.2'\n" > bsr_src/basicsr/version.py
$PIP install -q --no-build-isolation --no-deps -e bsr_src

echo "=== [5/6] 编 DCN ==="
cd bsr_src && $PY setup.py build_ext --inplace 2>&1 | tail -3
ls -la basicsr/ops/dcn/*.so

echo "=== [6/6] 验证 ==="
cd $WORK && $PY - <<'EOF'
import sys, types, torchvision
mod = types.ModuleType('torchvision.transforms.functional_tensor')
from torchvision.transforms import functional as F
for n in dir(F): setattr(mod, n, getattr(F, n))
sys.modules['torchvision.transforms.functional_tensor'] = mod
import torch
from basicsr.ops.dcn import ModulatedDeformConvPack
m = ModulatedDeformConvPack(32,32,3,stride=1,padding=1,deformable_groups=8).cuda()
x = torch.randn(1,32,24,24, device='cuda', requires_grad=True)
y = m(x); y.mean().backward()
print("DCN OK:", tuple(y.shape), "grad", float(x.grad.norm()))
EOF
echo "=== 环境就绪 ==="
```
